# Yepper Backend

This backend serves auth and onboarding routes for the Yepper app.

## Setup

1. Copy `backend/.env.example` to `backend/.env`
2. Set your `DATABASE_URL`, `GOOGLE_CLIENT_ID`, and `GOOGLE_CLIENT_SECRET`
3. Run `npm install`
4. Start the backend with `npm run dev`

The backend listens on port `5000` by default.
